# Credit Risk Analysis — Prédiction du défaut de remboursement

> Analyse de données et modèle prédictif pour estimer le risque qu'un client ne rembourse pas son crédit, de l'exploration jusqu'au dashboard décisionnel.

🚧 *Projet en cours de construction.*

## Contexte

Une banque gagne de l'argent en prêtant, mais chaque crédit non remboursé (défaut) est une perte. L'enjeu : **anticiper le risque de défaut pour mieux décider à qui prêter, en réduisant les pertes sans bloquer l'activité.**

Ce projet analyse les données de clients emprunteurs pour :
- comprendre quels facteurs sont liés au défaut de remboursement,
- construire un modèle prédictif du risque,
- restituer les résultats dans un dashboard pour les décideurs.

## Données

- **Source :** LendingClub Loan Data (Kaggle)
- **Taille :** 9578 clients, 14 variables
- **Description détaillée :** voir [`data_dictionary.md`](./data_dictionary.md)

## Démarche

1. **Exploration** des données (`notebooks/01_exploration.ipynb`)
2. **Nettoyage** et fiabilisation (Python / pandas)
3. **Analyse SQL** — test des hypothèses métier sur le risque
4. **Modélisation** — modèle prédictif de défaut (Python)
5. **Dashboard** — restitution visuelle (Power BI)
